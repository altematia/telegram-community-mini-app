# Telegram Community Mini App

Базовая инфраструктура будущего закрытого Telegram-сообщества. На этом этапе проект содержит только статическую тестовую страницу и Caddy с автоматическим HTTPS. Frontend и backend намеренно не добавлены.

## Состав

- Docker Compose — единая точка запуска;
- Caddy — HTTPS, HTTP/3 и раздача статической страницы;
- `site/index.html` — временная Hello World страница;
- именованные Docker volumes — сохранение сертификатов и состояния Caddy.

## Запуск

На сервере требуется только Docker Engine с Compose plugin.

```sh
cp .env.example .env
# Указать реальный email в .env
./scripts/deploy.sh
./scripts/verify.sh
```

Порт `443/tcp` и `443/udp` должен быть доступен снаружи. Порт 80 намеренно не публикуется из контейнера, чтобы не конфликтовать с существующим системным nginx/ISPmanager.

Для текущего тестового стенда используется доверенный короткоживущий сертификат Let's Encrypt на публичный IP и ACME-профиль `shortlived`. Caddy автоматически обновляет сертификат. После подключения собственного домена блок `tls` с профилем для IP можно убрать.

## Секреты

`.env`, VPN-конфиги, приватные ключи и Telegram bot token не коммитятся. Секреты должны передаваться на сервер отдельно и храниться с правами `0600`.

## VPN

Клиентская конфигурация пока не включена в репозиторий: тип и файл VPN должны быть подтверждены. После получения WireGuard/OpenVPN-конфига маршрутизация будет добавлена с отдельным маршрутом для SSH и автоматическим rollback, чтобы не потерять управление сервером.
